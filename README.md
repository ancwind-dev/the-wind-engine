# The Wind Engine

Движок под тактический шутер с видом сверху в духе Running With Rifles.
Архитектура и вехи — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск

Лаборатория — симуляция в окне, интерфейс как в Blender:

```
cargo run --release -p wind_lab
```

- Средняя или правая кнопка мыши — двигать вид, колесо — масштаб, Home — показать всю карту.
- Левый клик — выделить солдата. Пробел — пауза, → — шаг на один тик.
- `data/sim.ron` можно править прямо во время работы: оружие, ИИ и гранаты меняются сразу.

Замер производительности симуляции без окна:

```
cargo run --release -p wind_server -- --soldiers 1000 --map 1024 --ticks 6000
```

## Крейты

| Крейт | Что делает |
|---|---|
| `wind_sim` | симуляция: карта, солдаты, ИИ, пули, гранаты, разрушения, захват точек |
| `wind_server` | сервер без окна; пока — замер скорости симуляции |
| `wind_lab` | лаборатория для просмотра и настройки симуляции |
