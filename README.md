# The Wind Engine

Движок под тактический шутер с видом сверху в духе Running With Rifles.
Архитектура и вехи — в [notes/Архитектура.md](notes/Архитектура.md); все заметки проекта — в папке `notes/` (открывается в Obsidian как хранилище).

## Игра

```
cargo run --release -p wind_client
```

Открывается главное меню: бой против ИИ, игра по сети, наблюдение, настройки (имя, громкость, солдаты, карта).
Настройки хранятся в `%APPDATA%/The Wind Engine/settings.ron`. Esc — пауза.

WASD — идти, прицел мышью, ЛКМ — огонь, R — перезарядка, G — граната, 1–6 — где появиться (база, точки A–E), Tab — таблица, M — карта, колесо — масштаб (у наблюдателя; со своим солдатом камера, как в RWR, на 36 м), Esc — пауза, F3 — отладка, F4 — солдаты «точно как RWR» / «как было».
Раунд: побеждает команда, удержавшая все точки 60 с (или у кого больше точек через 20 минут) — правила в `data/sim.ron`, раздел `round`.
Сразу в бой, без меню: `--play` — против ИИ, `--connect 127.0.0.1:7777` — по сети, `--spectate` — наблюдать (Tab — следующий солдат),
`--bench 15 --soldiers 1000` — замер FPS (`--soldiers` — солдат на команду).
Звук: `--volume 0..1` (по умолчанию 0,8), `--mute` — без звука; `--export-sounds` — все звуки в WAV в `notes/Звуки/`.

Свои солдаты — `data/models/soldiers/<фракция>/*.xml` (формат RWR), оружие — `data/models/weapons/*.xml`,
кто в какой команде и с каким оружием (классы) — `data/factions.ron`, числа оружия — `data/weapons.ron`. `--follow N` — наблюдать сразу за солдатом №N.

Встроенные болванчики (если своих моделей нет) лежат в `data/models/soldier/*.vox` — их можно править в MagicaVoxel,
воксели цвета `#FF00FF` красятся в цвет команды. Пересоздать встроенные: `--export-models`.

## Лаборатория

Симуляция в окне, интерфейс как в Blender:

```
cargo run --release -p wind_lab
```

`--play-map руины` — сразу бой ИИ на карте из `data/maps` (руины — полигон для укрытий).

- Средняя или правая кнопка мыши — двигать вид, колесо — масштаб, Home — показать всю карту.
- Левый клик — выделить солдата. Пробел — пауза, → — шаг на один тик.
- `data/sim.ron` можно править прямо во время работы: ИИ и гранаты меняются сразу. Оружие — в `data/weapons.ron` (после перезапуска).
  Для игры по сети у сервера и игрока должны быть одинаковые `weapons.ron` и `factions.ron`.
- `--follow N` — выделить солдата №N и следовать за ним камерой вблизи.
- Кнопки 2D / 3D в углу вьюпорта (или `--3d`). В 3D: средняя кнопка — вращать, Shift+средняя или правая — двигать.
- Панель «Сеть»: поднять сервер прямо из лаборатории или подключиться к чужому.

## Студия персонажей

```
cargo run --release -p wind_lab -- --studio
```

Вкладка «Студия персонажей»: один солдат вблизи. Слева — модели (по фракциям) и оружие,
справа — анимация (стоит, шаг, бег, падение, замедление, фаза шага), ширина плавного сгиба
у суставов (0 — жёстко) и вид (скелет поверх модели, поворот, команда).

## Редактор карт

```
cargo run --release -p wind_lab -- --open пример
```

Вкладка «Редактор карт» в шапке лаборатории. 1 — стены (кисть, линия, дом), 2 — рельеф,
3 — покрытие земли, 4 — точки и базы, 5 — выделение (Ctrl+C — копировать, Ctrl+V — вставить,
Delete — стереть, «Сохранить как здание»), 6 — готовые здания (R — повернуть);
Ctrl — обратное действие, `[` `]` — размер кисти, Ctrl+Z — отмена, Ctrl+S — сохранить.
Свои здания — в `data/prefabs.ron` (текстом: `#` дом, `%` бетон, `=` забор, `.` пол). Карты лежат в `data/maps/<имя>/` (`map.ron` + слои PNG).
Играть на своей карте: кнопка «Играть на этой карте», `wind_client --map-file <имя>` или
`wind_server --map-file <имя>`.

Панель «Атмосфера» справа — свет, туман, цвета, обводка и виньетка карты (готовые варианты:
день, закат, пасмурно, пустыня, ночь). Сохраняется в `map.ron`, в игре видно так же.

## Игра по сети

Выделенный сервер (порт 7777):

```
cargo run --release -p wind_server
```

Имя, пароль и места: `--name "Сервер Артёма" --password тайна --max-players 24`. Пока сервер работает,
в его консоль можно писать команды: `игроки`, `кик 3 причина`, `бан 3 причина`, `разбан <адрес>`, `баны`,
`пароль [новый]`, `имя <новое>`, `стоп` («помощь» — список). Баны — в `data/bans.txt`.

Подключение проверяет адрес игрока (вызов с печатью), а дальше пакеты зашифрованы (X25519 +
ChaCha20-Poly1305): со стороны их не прочитать и не подделать — нельзя ни управлять чужим солдатом,
ни выкинуть игрока. Сервер пишет, сколько чужих пакетов отбил. Туман войны считает сервер: клиенту уходят только те враги, кого видит
его команда. Клиент и сервер должны быть одной версии протокола.

Подключиться и играть за солдата — WASD, прицел мышью, ЛКМ — огонь, G — граната:

```
cargo run --release -p wind_lab -- --connect 127.0.0.1:7777
```

Нагрузочные боты — подключаются как обычные игроки и считают трафик:

```
cargo run --release -p wind_bots -- --count 24 --seconds 30 --loss 0.1
```

При первом запуске сервера Windows может спросить разрешение для брандмауэра —
это нужно, чтобы к серверу могли подключиться с других компьютеров. Для игры
только на своём компьютере сервер можно запустить с `--host 127.0.0.1`.

## Крейты

| Крейт | Что делает |
|---|---|
| `wind_sim` | симуляция: карта, солдаты, ИИ и отряды со строем, игроки, пули, гранаты, разрушения, захват точек |
| `wind_net` | сеть: протокол, снимки с дельтами, чанки карты, сервер и клиент по UDP |
| `wind_server` | выделенный сервер; с `--bench` — замер скорости симуляции |
| `wind_bots` | нагрузочные боты-клиенты |
| `wind_render` | 3D на wgpu: воксели, карта по чанкам, солдаты, тени |
| `wind_client` | игра: против ИИ, по сети, наблюдатель, замер FPS |
| `wind_audio` | звук: синтез звуков, микшер, вывод через cpal |
| `wind_lab` | лаборатория: просмотр и настройка симуляции, свой сервер, игра по сети |
