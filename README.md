# The Wind Engine

Движок под тактический шутер с видом сверху в духе Running With Rifles.
Архитектура и вехи — в [notes/Архитектура.md](notes/Архитектура.md); все заметки проекта — в папке `notes/` (открывается в Obsidian как хранилище).

## Лаборатория

Симуляция в окне, интерфейс как в Blender:

```
cargo run --release -p wind_lab
```

- Средняя или правая кнопка мыши — двигать вид, колесо — масштаб, Home — показать всю карту.
- Левый клик — выделить солдата. Пробел — пауза, → — шаг на один тик.
- `data/sim.ron` можно править прямо во время работы: оружие, ИИ и гранаты меняются сразу.
- Панель «Сеть»: поднять сервер прямо из лаборатории или подключиться к чужому.

## Игра по сети

Выделенный сервер (порт 7777):

```
cargo run --release -p wind_server
```

Подключиться и играть за солдата — WASD, прицел мышью, ЛКМ — огонь, G — граната:

```
cargo run --release -p wind_lab -- --connect 127.0.0.1:7777
```

Нагрузочные боты — подключаются как обычные игроки и считают трафик:

```
cargo run --release -p wind_bots -- --count 24 --seconds 30 --loss 0.1
```

При первом запуске сервера Windows может спросить разрешение для брандмауэра —
это нужно, чтобы к серверу могли подключиться с других компьютеров. Для игры
только на своём компьютере сервер можно запустить с `--host 127.0.0.1`.

## Замеры и тесты

```
cargo run --release -p wind_server -- --bench --soldiers 1000 --map 1024 --ticks 6000
```

```
cargo test --release
```

## Крейты

| Крейт | Что делает |
|---|---|
| `wind_sim` | симуляция: карта, солдаты, ИИ, игроки, пули, гранаты, разрушения, захват точек |
| `wind_net` | сеть: протокол, снимки с дельтами, чанки карты, сервер и клиент по UDP |
| `wind_server` | выделенный сервер; с `--bench` — замер скорости симуляции |
| `wind_bots` | нагрузочные боты-клиенты |
| `wind_lab` | лаборатория: просмотр и настройка симуляции, свой сервер, игра по сети |
