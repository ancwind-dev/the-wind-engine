# Как устроены прицел и обзор в RWR

Источники: статья вики «Line of Sight, Vision» (сам фандом закрыт проверкой на бота —
прочитали копию в web.archive.org) и файлы игры: `factions/default.ai`,
`factions/default_base.character`, `weapons/base_primary.weapon`. Берём только числа
и устройство — код свой.

## Что пишет вики

- **Курсор раздвигает обзор.** Курсор у края экрана — в эту сторону видно примерно на
  80 % дальше (для оружия без прицела). Зато сзади видно меньше. Это главное
  преимущество игрока над ИИ: кто заметил первым, тот обычно и выиграл.
- **У игрока нет тумана войны.** Всех врагов на своём экране он видит, даже за стенами.
  **ИИ — только по прямой видимости:** за стеной тебя не заметит.
- Оружие с оптикой раздвигает обзор ещё дальше (`sight_range_modifier`); у ИИ тоже.
- **Заметность зависит от стойки:** пригнувшегося видно хуже, лежащего — ещё хуже; ИИ
  к тому же медленнее реагирует. Чем дальше — тем медленнее. **Выстрел выдаёт сразу.**
- Ночью ИИ видит хуже; поднятый тревогой сектор видит дальше.

## Числа из файлов игры

| что | значение |
|---|---|
| обзор ИИ: командир / боец | 35 / 30 м (`leader_sight_range`, `team_member_sight_range`) |
| стреляющего видно дальше | ×1,7, но не дальше 40 м (`sight_range_muzzle_factor`, `max_sight_range_with_muzzle`) |
| реакция ИИ днём / ночью | 0,3–0,6 / 0,8–1,1 с (`day_reaction_time_to_fight_*`) |
| очередь ИИ и пауза | 0,3 ± 0,2 с и 1,2 ± 0,6 с (`burst_time`, `wait_time`) |
| заметность: бежит / идёт / стоит / пригнулся / лежит | 1,0 / 0,95 / 0,88 / 0,72 / 0,6 (`detectability_*`) |
| точность: бег / шаг / стоя / пригнувшись / лёжа | 0,3 / 0,675 / 0,85 / 0,9 / 0,95 (`stance accuracy`) |
