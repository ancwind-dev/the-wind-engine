# Звуки

Все звуки игры — синтез ([[Звук — синтез]]). Файлы WAV здесь создаются командой

```
cargo run --release -p wind_client -- --export-sounds
```

и в git не хранятся (пересоздаются за секунду). Если ниже пусто — запусти команду.
