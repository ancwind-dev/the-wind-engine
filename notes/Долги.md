# Долги

Известные проблемы, которые сознательно отложили. Решили — вычёркиваем и пишем, где.

| Что | Чем плохо | Когда чинить |
|---|---|---|
| Поле путей пересчитывается целиком за один тик | На карте 1 км пик 28,7 мс, на 2 км будет за бюджетом | Вместе с делением карты на чанки |
| ~~Подкрепления идут к точке колонной по одному~~ | Смягчено в вехе 2: личное боковое смещение, колонна идёт полосой. Настоящий строй — с отрядами | Когда будет отряд и командир |
| Генератор карт временный | Дома и заборы случайные | Веха 3, редактор карт |
| Нет защиты от подмены адреса клиента в сети | Кто-то может слать пакеты от чужого имени | Перед публичными серверами |
| Нет предсказания своего солдата на клиенте | Управление запаздывает на пинг + до 50 мс ожидания тика | Веха 4, когда появится настоящее управление |
| Кого видит клиент — перебор всех солдат для каждого клиента | 4000 солдат × 24 клиента ≈ 100 тыс. проверок за тик; пока дёшево | Когда сетка станет общей для симуляции и сети |
| Один чанк карты может не влезть в бюджет пакета | Пакет больше ~1200 Б может дробиться на уровне IP и чаще теряться | Если увидим много потерь на разрушенных картах |
| Нет шифрования и сжатия | Пакеты читаемы; сжатие могло бы срезать ещё 20–40% | Перед публичными серверами |
| Симуляция и отрисовка в одном потоке клиента | Тяжёлый тик (пересчёт путей) даст рывок кадра | Когда клиент станет играть на больших картах |
| Нет уровней детализации (LOD) для солдат | Издалека рисуем все ~200 треугольников солдата; на 4000 солдат ещё 435 FPS | Если упрёмся в GPU на слабых видеокартах |
| ~~Солдаты выглядят не как в RWR~~ | Сделано 2026-10-26: солдаты рисуются точками, как у RWR, — см. [[Веха 5 — стиль RWR#Доводка: солдаты как в RWR]] | — |
| Силуэт сквозь стены виден у всех солдат | В сетевой игре клиент и так получает только видимых, но в локальной игре видно врагов за стенами | Вместе с туманом войны в вехе 6: силуэт только у своих |
| Солдаты-точки не получают теней | Солдат в тени дома такой же яркий, как на солнце (у RWR так же) | Если будет выбиваться из картинки |
| Проход нормалей и глубины рисует сцену второй раз | −25 % FPS на 2000 солдат (207 → 160) | Если упрёмся: писать нормаль и глубину вторым выходом основного прохода (мешает сглаживание MSAA) или не рисовать дальних солдат в этот проход |
| Следы боя не тускнеют и не сохраняются в сети отдельно | Клиент, подключившийся посреди матча, не видит старых следов; к концу долгого матча земля вся в пятнах | Когда будет режим матча с длительностью |
| Подпалины только от взрывов на земле | Стены не чернеют, от пуль следов нет | Вместе с разрушением стен в вехе 6 |
| Тень только вокруг центра экрана | На дальнем виде дальние объекты без теней | Каскадные тени — когда будет важна картинка издалека |
| Солдат не видно в момент смерти — исчезают сразу | Нет анимации падения и тел | Веха 4 |
| ~~Земля плоская~~ | Рельеф есть с вехи 3, но только для картинки | — |
| Рельеф не влияет на симуляцию | Холм не закрывает видимость и не замедляет бег | Когда понадобится тактика на высотах |
| В редакторе нет копирования, вставки и готовых зданий | Каждый дом рисуется вручную | Когда начнём делать настоящие карты |
| 2D-картинка карты в редакторе пересобирается целиком на каждый мазок | На картах 2048 м кисть может подтормаживать | Если будет заметно — обновлять только изменённые чанки |
| Переименование карты сохраняет её в новую папку, старая остаётся | Можно запутаться в копиях | Вместе с нормальным диалогом «Сохранить как» |
| ~~Нет уровней детализации для своих солдат~~ | Сделано 2026-10-26: у точек три уровня (2488 / 760 / 235 точек). Тени по-прежнему гранями без уровней | — |
| Анимации процедурные | Нет приседа, лёжа, перезарядки, броска гранаты | Вместе с редактором анимаций |
| У всех USMC одно оружие (M4) | Гранатомётчик без гранатомёта | Веха 5 — классы и оружие из данных |
| Сетевой клиент видит тело, только если видел солдата в момент смерти | Убитые вдали «исчезают» без тела | Если станет заметно — передавать смерть как событие с местом |
| Грани между частями солдата строятся | Лишние грани внутри на сгибах | Если станет узким местом |
