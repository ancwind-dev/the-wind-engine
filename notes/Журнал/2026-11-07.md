## Логотип — значок движка

Хозяин положил в проект логотип (`logo.png`), потом заменил его новым, «намного
удачнее»: синяя геометрическая фигура на прозрачном, 1254 × 1254.

Значки делает `icon/make.py` (запуск из корня: `python icon/make.py`). Заменил логотип —
запусти скрипт и пересобери, больше ничего трогать не нужно.

### В файле .exe

Значок самого файла (в проводнике и на ярлыке) вшивается ресурсом Windows при сборке:
у `wind_client`, `wind_lab`, `wind_server` и `wind_bots` есть `build.rs`, он через
сборочную библиотеку `winresource` (скачана с согласия хозяина) кладёт `icon/wind.ico`
в `.exe`. Нужен `rc.exe` из Windows SDK — он установлен. На других системах `build.rs`
ничего не делает. Проверил, достав значок из всех четырёх собранных `.exe`.

### Белый, с подложкой для светлой темы

Хозяин: «сделай его белым и для светлых тем в Windows чёрную подложку». Теперь логотип
белый: окно при тёмной теме — белый на прозрачном, при светлой — на чёрной скруглённой
подложке; меняется на ходу вместе с темой (`wind_render::app_icon`). В `.exe` — с

## Веха 14 — оболочка движка

Хозяин хочет «переформатировать движок»: окно выбора проекта, главный экран с выбором
редактора, приятный интерфейс с тёмно-синим акцентом (как Blender, Enfusion Workbench),
выбор языка — английский и русский. Всё сделано, подробности — [[Веха 14 — оболочка движка]].

- **Проекты.** `wind.project` в корне — наша игра стала проектом. Новый проект — из шаблона
  («копия нашей игры» или «пустой») в `Документы/The Wind Engine`. Редакторы берут данные
  из папки проекта (раньше — из папки, откуда запустили).
- **Окно выбора проекта** — первое при запуске `wind_lab`: недавние, наша игра, новый,
  открыть папку, настройки.
- **Главный экран** — плитки «Лаборатория», «Редактор карт», «Студия персонажей», «Играть»
  (запускает игру в папке проекта), карты проекта, сводка. Назад — логотип в шапке.
- **Тема** — холодные тёмно-серые панели, акцент — цвет логотипа `#2a5286`.
- **Перевод** — 430 строк интерфейса через `t()`/`f()`, английский — в `locale/en.ron`;
  выбор в «Настройки движка» (там же масштаб интерфейса), меняется сразу.
  [[Перевод интерфейса — русский текст как ключ]]. Строки обернул скриптом; заголовок
  файла клипа и имена-данные («Копия», «новая карта») оставил русскими — их пишут в файлы
  и по ним сравнивают.
